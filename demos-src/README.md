# Motion Index video studies

These four original, silent 3D scenes interpret Shaan Johari's written Part 4 recipes; they do not use the source GIFs or frames. The fifth study, `design-pack`, is an original GSAP composition that interprets the editing style of EA DESIGN's design-pack reel; it uses none of that reel's frames, footage or artwork. Each folder is a self-contained HyperFrames composition with vendored runtime files and locally embedded typefaces. The fonts are distributed under the included SIL Open Font Licenses; Three.js is MIT licensed, and GSAP's distribution header names its standard license.

Each composition is 1088 × 800, five seconds long and driven by deterministic seek time. The final portion reverses the move to return smoothly to frame one. The card and receipt masters are sampled at 60 fps and blended down to 30 fps to give their fast movements a short exposure blur.

To update a study, run `npx hyperframes check demos-src/<id>` and `npx hyperframes snapshot demos-src/<id> --at 0,1.5,3.5,4.9667 --no-end` from the repository root. Review the frames, render with the version pinned in the study's `package.json`, then encode a silent H.264 MP4 with `-crf 28 -movflags +faststart` into `public/demos/<id>.mp4`; export its first frame as `public/demos/<id>.jpg`. Run `npm run build` and `npm run check` afterward.

The 3D studies `low-poly`, `soft-clay`, `tiny-diorama`, `neon-sign`, `blueprint-build`, `paper-popup`, `spotlight-stage`, `exploded-view`, `marble-run`, `x-ray`, `led-wall`, `inflated`, `painted`, `circuit-city` and `glass-light` are original three.js scenes that re-create looks from Futurepedia's 3D Style Atlas (https://www.futurepedia.io/resources/3d-style-atlas/view). They use none of the atlas's code, prompts or clips. Each is 1088 × 800, six seconds long, and resets to its first state in the last half second. Render them with `-w 1` and use the frame at 4.6 s as the poster. The Fraunces and Caveat fonts used by `paper-popup`, `spotlight-stage` and `painted` come from the @fontsource packages and are under the SIL Open Font License included beside them.
